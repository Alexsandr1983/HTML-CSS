## Введение в Flexbox

### Что такое Flexbox

CSS Flexbox (Flexible Box Layout) — это модуль компоновки в CSS, который предоставляет удобный и мощный способ распределения пространства между элементами в контейнере, даже когда их размер неизвестен или динамичен. Он был разработан для улучшения существующих методов верстки (таких как блочная и строчная модели) и предлагает более эффективный способ расположения, выравнивания и распределения пространства между элементами.

Flexbox работает в одномерном пространстве, что делает его идеальным для создания строк или столбцов элементов. В отличие от Grid Layout, который предназначен для двумерных макетов, Flexbox фокусируется на одном измерении за раз: либо на горизонтальном (строка), либо на вертикальном (столбец).

### Основные преимущества использования Flexbox

1. **Гибкость**: Элементы могут растягиваться и сжиматься в зависимости от доступного пространства.
2. **Простота вертикального выравнивания**: Flexbox делает вертикальное центрирование элементов тривиальной задачей.
3. **Порядок элементов**: Возможность изменять порядок отображения элементов без изменения HTML-структуры.
4. **Распределение пространства**: Контроль над тем, как распределяется свободное пространство между элементами.
5. **Двунаправленность**: Возможность работать как в горизонтальном, так и в вертикальном направлении.
6. **Адаптивность**: Легкая адаптация макета под различные размеры экрана.

### Терминология

Перед тем как погрузиться в детали Flexbox, важно понять основные термины:

1. **Flex-контейнер (Flex Container)**: Родительский элемент, к которому применяется свойство `display: flex` или `display: inline-flex`.
2. **Flex-элементы (Flex Items)**: Дочерние элементы flex-контейнера.
3. **Главная ось (Main Axis)**: Основная ось, вдоль которой располагаются flex-элементы. Направление определяется свойством `flex-direction`.
4. **Поперечная ось (Cross Axis)**: Ось, перпендикулярная главной оси.
5. **Main Start/Main End**: Начало и конец главной оси.
6. **Cross Start/Cross End**: Начало и конец поперечной оси.
7. **Main Size**: Размер flex-элемента вдоль главной оси.
8. **Cross Size**: Размер flex-элемента вдоль поперечной оси.

### Браузерная поддержка

Flexbox поддерживается всеми современными браузерами. Однако есть некоторые нюансы при работе со старыми версиями браузеров:

- Internet Explorer 10 поддерживает Flexbox с устаревшим синтаксисом и имеет ряд ошибок.
- Internet Explorer 11 поддерживает Flexbox, но также имеет несколько проблем.
- Старые версии Safari, Chrome и Firefox могут требовать префиксов `-webkit-`, `-moz-` и `-ms-`.

Для обеспечения максимальной совместимости рекомендуется использовать автопрефиксер в вашем рабочем процессе.

## Начало работы с Flexbox

### Flex-контейнер

Чтобы начать использовать Flexbox, вам нужно установить свойство `display` для родительского элемента:

```css
.container {
  display: flex; /* или inline-flex */
}
```

После этого вы можете использовать другие свойства Flexbox для настройки поведения контейнера и его дочерних элементов.

### Flex-элементы

Все прямые дочерние элементы flex-контейнера автоматически становятся flex-элементами. Обратите внимание, что только непосредственные дочерние элементы становятся flex-элементами. Внуки и другие вложенные элементы не будут автоматически затронуты.

```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

Использование различных вариантов выравнивания:

```css
/* Выравнивание по центру */
.container-1 {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* Равномерное распределение по всей ширине */
.container-2 {
  display: flex;
  justify-content: space-between;
  align-items: flex-start;
}

/* Равномерное распределение с отступами */
.container-3 {
  display: flex;
  justify-content: space-around;
  align-items: flex-end;
}

/* Выравнивание по базовой линии */
.container-4 {
  display: flex;
  justify-content: flex-start;
  align-items: baseline;
}
```

### Изменение порядка элементов

Изменение порядка элементов без изменения HTML-структуры:

```html
<div class="container">
  <div class="item first">1</div>
  <div class="item second">2</div>
  <div class="item third">3</div>
</div>
```

```css
.container {
  display: flex;
}

/* Порядок отображения: 3, 1, 2 */
.first { order: 2; }
.second { order: 3; }
.third { order: 1; }
```

### Колонки одинаковой ширины

Создание колонок одинаковой ширины:

```html
<div class="columns">
  <div class="column">Колонка 1</div>
  <div class="column">Колонка 2</div>
  <div class="column">Колонка 3</div>
</div>
```

```css
.columns {
  display: flex;
  gap: 20px; /* Отступы между колонками */
}

.column {
  flex: 1; /* Все колонки одинаковой ширины */
  padding: 20px;
  background-color: #f0f0f0;
}
```

### Адаптивный макет с Flexbox

Создание адаптивного макета, который меняет структуру на разных размерах экрана:

```html
<div class="layout">
  <header class="header">Шапка</header>
  <div class="content">
    <main class="main">Основное содержимое</main>
    <aside class="sidebar">Боковая панель</aside>
  </div>
  <footer class="footer">Подвал</footer>
</div>
```

```css
.layout {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}

.header, .footer {
  padding: 20px;
  background-color: #333;
  color: white;
}

.content {
  display: flex;
  flex: 1;
}

.main {
  flex: 3; /* Занимает 3/4 доступного пространства */
  padding: 20px;
}

.sidebar {
  flex: 1; /* Занимает 1/4 доступного пространства */
  padding: 20px;
  background-color: #f0f0f0;
}

/* Адаптивность: на экранах меньше 768px меняем структуру */
@media (max-width: 768px) {
  .content {
    flex-direction: column; /* Меняем направление на вертикальное */
  }
  
  .main, .sidebar {
    flex: auto; /* Отменяем пропорции */
  }
}
```

## Продвинутые техники

### Вложенные Flexbox-контейнеры

Вы можете вкладывать Flexbox-контейнеры друг в друга для создания более сложных макетов:

```html
<div class="outer-container">
  <div class="inner-container">
    <div class="item">1</div>
    <div class="item">2</div>
  </div>
  <div class="inner-container">
    <div class="item">3</div>
    <div class="item">4</div>
  </div>
</div>
```

```css
.outer-container {
  display: flex;
  gap: 20px;
}

.inner-container {
  display: flex;
  flex-direction: column;
  gap: 10px;
  flex: 1;
}

.item {
  padding: 20px;
  background-color: #f0f0f0;
}
```

### Комбинирование Flexbox с Grid Layout

Часто для создания комплексных макетов удобно комбинировать Flexbox с Grid Layout:

```html
<div class="grid-container">
  <header class="header">Шапка</header>
  <nav class="nav">Навигация</nav>
  <main class="main">Основное содержимое</main>
  <aside class="sidebar">Боковая панель</aside>
  <footer class="footer">Подвал</footer>
</div>
```

```css
/* Общая структура с помощью Grid */
.grid-container {
  display: grid;
  grid-template-areas:
    "header header"
    "nav main"
    "sidebar main"
    "footer footer";
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto auto 1fr auto;
  min-height: 100vh;
}

.header { grid-area: header; }
.nav { grid-area: nav; }
.main { grid-area: main; }
.sidebar { grid-area: sidebar; }
.footer { grid-area: footer; }

/* Использование Flexbox внутри Grid-элементов */
.nav {
  display: flex;
  flex-direction: column;
}

.main {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

/* Адаптивность для мобильных устройств */
@media (max-width: 768px) {
  .grid-container {
    grid-template-areas:
      "header"
      "nav"
      "main"
      "sidebar"
      "footer";
    grid-template-columns: 1fr;
  }
  
  .nav {
    flex-direction: row;
    justify-content: space-between;
  }
}
```

### Автоматическое выравнивание и распределение пространства

Создание автоматически выровненной сетки элементов:

```html
<div class="grid">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>
```

```css
.grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.item {
  flex: 1 1 calc(33.333% - 20px); /* Три колонки с учетом отступа */
  min-width: 250px; /* Минимальная ширина для адаптивности */
  height: 200px;
  background-color: #f0f0f0;
}
```

### Flexbox и медиа-запросы

Использование Flexbox в сочетании с медиа-запросами для создания адаптивного макета:

```css
.card-container {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card {
  flex: 1 1 300px; /* Базовая ширина 300px, может расти и сжиматься */
  max-width: 100%;
  padding: 20px;
  border: 1px solid #ddd;
  border-radius: 5px;
}

/* Большие экраны: 4 карточки в ряд */
@media (min-width: 1200px) {
  .card {
    flex-basis: calc(25% - 20px);
    max-width: calc(25% - 20px);
  }
}

/* Средние экраны: 3 карточки в ряд */
@media (max-width: 1199px) and (min-width: 768px) {
  .card {
    flex-basis: calc(33.333% - 20px);
    max-width: calc(33.333% - 20px);
  }
}

/* Маленькие экраны: 2 карточки в ряд */
@media (max-width: 767px) and (min-width: 480px) {
  .card {
    flex-basis: calc(50% - 20px);
    max-width: calc(50% - 20px);
  }
}

/* Очень маленькие экраны: 1 карточка в ряд */
@media (max-width: 479px) {
  .card {
    flex-basis: 100%;
    max-width: 100%;
  }
}
```

## Распространенные проблемы и их решения

### Переполнение контейнера

Одна из распространенных проблем — переполнение flex-контейнера, когда элементы не помещаются в одну строку/столбец:

**Проблема:**
```css
.container {
  display: flex;
  /* Элементы не умещаются и выходят за пределы контейнера */
}
```

**Решение:**
```css
.container {
  display: flex;
  flex-wrap: wrap; /* Позволяет элементам переноситься на новую строку */
}
```

Или, если вы хотите сжать элементы:

```css
.container {
  display: flex;
}

.item {
  flex-shrink: 1; /* Элементы будут сжиматься при необходимости */
  min-width: 0; /* Важно для корректного сжатия */
}
```

### Неожиданное поведение flex-shrink

Иногда элементы сжимаются не так, как ожидается:

**Проблема:**
```css
.container {
  display: flex;
}

.item {
  /* Элементы сжимаются неравномерно или не сжимаются вообще */
}
```

**Решение:**
```css
.container {
  display: flex;
}

.item {
  flex-shrink: 1; /* Контролирует сжатие */
  min-width: 0; /* Важно для корректного сжатия */
  /* Также может быть полезно добавить overflow: class="item">2</div>
  <div class="item">3</div>
</div>
```

В этом примере элементы с классом `.item` являются flex-элементами, а `.container` — flex-контейнером.

### Ось main и cross

Важно понимать концепцию осей в Flexbox:

- **Главная ось (Main Axis)**: По умолчанию идет слева направо. Но ее направление можно изменить с помощью свойства `flex-direction`.
- **Поперечная ось (Cross Axis)**: Перпендикулярна главной оси. Если главная ось идет горизонтально, то поперечная — вертикально, и наоборот.

Понимание осей критически важно для правильного использования свойств Flexbox, таких как `justify-content` (выравнивание по главной оси) и `align-items` (выравнивание по поперечной оси).

## Свойства flex-контейнера

### display: flex/inline-flex

Это базовое свойство, которое определяет элемент как flex-контейнер.

```css
.container {
  display: flex; /* Создает блочный flex-контейнер */
}
```

или

```css
.container {
  display: inline-flex; /* Создает строчный flex-контейнер */
}
```

Разница между ними заключается в том, как контейнер ведет себя по отношению к окружающим элементам. Если вы используете `display: flex`, контейнер занимает всю доступную ширину (как блочный элемент). С `display: inline-flex` контейнер будет занимать только необходимую ширину (как строчный элемент).

### flex-direction

Определяет направление главной оси, то есть как flex-элементы будут располагаться внутри контейнера.

```css
.container {
  flex-direction: row; /* По умолчанию: слева направо */
}
```

Возможные значения:

- `row`: Элементы располагаются в строку слева направо (значение по умолчанию).
- `row-reverse`: Элементы располагаются в строку справа налево.
- `column`: Элементы располагаются в столбец сверху вниз.
- `column-reverse`: Элементы располагаются в столбец снизу вверх.

Это свойство также меняет направление главной и поперечной осей. Например, если `flex-direction: column`, то главная ось идет сверху вниз, а поперечная — слева направо.

### flex-wrap

Определяет, должны ли flex-элементы располагаться в одну строку/столбец или могут переноситься на новую строку/столбец, если не помещаются.

```css
.container {
  flex-wrap: nowrap; /* По умолчанию: без переноса */
}
```

Возможные значения:

- `nowrap`: Все элементы пытаются разместиться в одной строке/столбце (значение по умолчанию).
- `wrap`: Элементы переносятся на новую строку/столбец, если не помещаются.
- `wrap-reverse`: Элементы переносятся, но в обратном направлении.

### flex-flow

Сокращенное свойство для `flex-direction` и `flex-wrap`.

```css
.container {
  flex-flow: row wrap; /* flex-direction: row; flex-wrap: wrap; */
}
```

Это удобный способ установить оба свойства в одной строке.

### justify-content

Определяет выравнивание элементов вдоль главной оси.

```css
.container {
  justify-content: flex-start; /* По умолчанию: в начале главной оси */
}
```

Возможные значения:

- `flex-start`: Элементы выравниваются к началу главной оси (значение по умолчанию).
- `flex-end`: Элементы выравниваются к концу главной оси.
- `center`: Элементы выравниваются по центру главной оси.
- `space-between`: Элементы равномерно распределяются вдоль главной оси; первый элемент в начале, последний в конце.
- `space-around`: Элементы равномерно распределяются с равным пространством вокруг них.
- `space-evenly`: Элементы равномерно распределяются с равным пространством между ними, включая первый и последний элементы.

### align-items

Определяет, как flex-элементы выравниваются вдоль поперечной оси.

```css
.container {
  align-items: stretch; /* По умолчанию: растягиваются на всю высоту/ширину контейнера */
}
```

Возможные значения:

- `stretch`: Элементы растягиваются, чтобы заполнить контейнер (значение по умолчанию).
- `flex-start`: Элементы выравниваются к началу поперечной оси.
- `flex-end`: Элементы выравниваются к концу поперечной оси.
- `center`: Элементы выравниваются по центру поперечной оси.
- `baseline`: Элементы выравниваются по базовой линии текста.

### align-content

Определяет, как строки (в случае, если элементы переносятся — `flex-wrap: wrap`) выравниваются вдоль поперечной оси. Если все элементы находятся в одной строке или столбце, это свойство не имеет эффекта.

```css
.container {
  align-content: stretch; /* По умолчанию: строки растягиваются на всю высоту/ширину контейнера */
}
```

Возможные значения:

- `stretch`: Строки растягиваются, чтобы заполнить контейнер (значение по умолчанию).
- `flex-start`: Строки упаковываются к началу поперечной оси.
- `flex-end`: Строки упаковываются к концу поперечной оси.
- `center`: Строки упаковываются по центру поперечной оси.
- `space-between`: Строки равномерно распределяются; первая строка в начале, последняя в конце.
- `space-around`: Строки равномерно распределяются с равным пространством вокруг них.
- `space-evenly`: Строки равномерно распределяются с равным пространством между ними, включая первую и последнюю строки.

### gap, row-gap, column-gap

Эти свойства устанавливают промежутки (отступы) между flex-элементами.

```css
.container {
  gap: 10px; /* Отступы между элементами 10px по обеим осям */
  row-gap: 20px; /* Отступы между строками 20px */
  column-gap: 10px; /* Отступы между колонками 10px */
}
```

Свойство `gap` является сокращением для `row-gap` и `column-gap`:

```css
.container {
  gap: 20px 10px; /* row-gap: 20px; column-gap: 10px; */
}
```

Эти свойства особенно полезны, когда вы хотите создать сетку элементов с равномерными промежутками, но без необходимости добавлять маргины к самим элементам.

## Свойства flex-элементов

### order

Определяет порядок отображения flex-элемента относительно других элементов в контейнере.

```css
.item {
  order: 0; /* По умолчанию: 0 */
}
```

По умолчанию все элементы имеют значение `order: 0`. Элементы с одинаковым значением `order` отображаются в порядке их появления в HTML. Элементы с меньшим значением `order` отображаются перед элементами с большим значением.

```css
.item1 { order: 3; } /* Будет отображаться после .item2 и .item3 */
.item2 { order: 1; } /* Будет отображаться перед .item1, но после .item3 */
.item3 { order: 0; } /* Будет отображаться перед .item1 и .item2 */
```

### flex-grow

Определяет, как flex-элемент может расти относительно других элементов в контейнере, если есть свободное пространство.

```css
.item {
  flex-grow: 0; /* По умолчанию: 0 */
}
```

Значение `0` означает, что элемент не будет расти. Значение `1` означает, что элемент будет расти, чтобы заполнить доступное пространство. Если несколько элементов имеют `flex-grow: 1`, они будут расти равномерно. Если один элемент имеет `flex-grow: 2`, а другие `flex-grow: 1`, элемент с `flex-grow: 2` будет расти в два раза быстрее.

```css
.item1 { flex-grow: 1; } /* Будет занимать 1/4 доступного пространства */
.item2 { flex-grow: 2; } /* Будет занимать 2/4 доступного пространства */
.item3 { flex-grow: 1; } /* Будет занимать 1/4 доступного пространства */
```

### flex-shrink

Определяет, как flex-элемент может сжиматься относительно других элементов в контейнере, если не хватает пространства.

```css
.item {
  flex-shrink: 1; /* По умолчанию: 1 */
}
```

Значение `1` означает, что элемент будет сжиматься, если не хватает пространства. Значение `0` означает, что элемент не будет сжиматься. Если несколько элементов имеют `flex-shrink: 1`, они будут сжиматься равномерно. Если один элемент имеет `flex-shrink: 2`, а другие `flex-shrink: 1`, элемент с `flex-shrink: 2` будет сжиматься в два раза быстрее.

```css
.item1 { flex-shrink: 0; } /* Не будет сжиматься */
.item2 { flex-shrink: 1; } /* Будет сжиматься нормально */
.item3 { flex-shrink: 2; } /* Будет сжиматься в два раза быстрее, чем .item2 */
```

### flex-basis

Определяет начальный размер flex-элемента перед распределением свободного пространства.

```css
.item {
  flex-basis: auto; /* По умолчанию: auto */
}
```

Значение `auto` означает, что размер элемента будет определяться его контентом или явно заданной шириной/высотой. Вы также можете использовать конкретные значения, такие как `200px` или `50%`.

```css
.item1 { flex-basis: auto; } /* Размер на основе контента */
.item2 { flex-basis: 200px; } /* Начальный размер 200px */
.item3 { flex-basis: 50%; } /* Начальный размер 50% от размера контейнера */
```

### flex (сокращенное свойство)

Сокращенное свойство для `flex-grow`, `flex-shrink` и `flex-basis`.

```css
.item {
  flex: 0 1 auto; /* По умолчанию: flex-grow: 0; flex-shrink: 1; flex-basis: auto; */
}
```

Существуют также удобные короткие значения:

```css
.item1 { flex: 1; } /* flex: 1 1 0%; */
.item2 { flex: auto; } /* flex: 1 1 auto; */
.item3 { flex: none; } /* flex: 0 0 auto; */
```

Рекомендуется использовать сокращенное свойство `flex` вместо отдельных свойств для лучшей совместимости с браузерами.

### align-self

Позволяет переопределить значение `align-items` для отдельного flex-элемента.

```css
.item {
  align-self: auto; /* По умолчанию: auto */
}
```

Возможные значения такие же, как у `align-items`, плюс `auto`:

- `auto`: Наследует значение свойства `align-items` контейнера (значение по умолчанию).
- `stretch`: Элемент растягивается, чтобы заполнить контейнер.
- `flex-start`: Элемент выравнивается к началу поперечной оси.
- `flex-end`: Элемент выравнивается к концу поперечной оси.
- `center`: Элемент выравнивается по центру поперечной оси.
- `baseline`: Элемент выравнивается по базовой линии текста.

```css
.container {
  align-items: flex-start; /* Все элементы выравниваются к началу поперечной оси */
}

.special-item {
  align-self: center; /* Этот элемент выравнивается по центру поперечной оси */
}
```

## Практические примеры и задачи

### Центрирование элемента по горизонтали и вертикали

Одна из самых распространенных задач в CSS — центрирование элемента по горизонтали и вертикали. С Flexbox это стало очень простым:

```css
.container {
  display: flex;
  justify-content: center; /* Центрирование по горизонтали */
  align-items: center; /* Центрирование по вертикали */
  height: 100vh; /* Высота контейнера на весь экран */
}
```

### Навигационное меню

Создание горизонтального навигационного меню с Flexbox:

```html
<nav class="nav">
  <a href="#" class="nav-item">Главная</a>
  <a href="#" class="nav-item">О нас</a>
  <a href="#" class="nav-item">Услуги</a>
  <a href="#" class="nav-item">Портфолио</a>
  <a href="#" class="nav-item">Контакты</a>
</nav>
```

```css
.nav {
  display: flex;
  justify-content: space-between; /* Распределение элементов по всей ширине */
  background-color: #333;
  padding: 10px;
}

.nav-item {
  color: white;
  text-decoration: none;
  padding: 10px;
}

.nav-item:hover {
  background-color: #555;
}
```

### Карточки одинаковой высоты

Создание сетки из карточек одинаковой высоты:

```html
<div class="cards">
  <div class="card">
    <h2>Карточка 1</h2>
    <p>Краткое описание.</p>
    <button>Подробнее</button>
  </div>
  <div class="card">
    <h2>Карточка 2</h2>
    <p>Более длинное описание, которое займет несколько строк текста.</p>
    <button>Подробнее</button>
  </div>
  <div class="card">
    <h2>Карточка 3</h2>
    <p>Еще одно описание.</p>
    <button>Подробнее</button>
  </div>
</div>
```

```css
.cards {
  display: flex;
  gap: 20px; /* Отступы между карточками */
  flex-wrap: wrap; /* Перенос карточек на новую строку при необходимости */
}

.card {
  flex: 1 1 300px; /* Гибкость, минимальная ширина 300px */
  display: flex;
  flex-direction: column; /* Вертикальное расположение элементов внутри карточки */
  border: 1px solid #ddd;
  padding: 20px;
  border-radius: 5px;
}

.card button {
  margin-top: auto; /* Кнопка прижата к низу карточки */
}
```

### Макет страницы с шапкой, сайдбаром и основным содержимым

Классический макет веб-страницы с использованием Flexbox:

```html
<div class="page">
  <header class="header">Шапка сайта</header>
  <div class="content">
    <aside class="sidebar">Боковая панель</aside>
    <main class="main">Основное содержимое</main>
  </div>
  <footer class="footer">Подвал сайта</footer>
</div>
```

```css
.page {
  display: flex;
  flex-direction: column;
  min-height: 100vh; /* Минимальная высота страницы - весь экран */
}

.header {
  background-color: #333;
  color: white;
  padding: 20px;
}

.content {
  display: flex;
  flex: 1; /* Занимает все доступное пространство */
}

.sidebar {
  background-color: #f0f0f0;
  padding: 20px;
  width: 250px;
}

.main {
  flex: 1; /* Занимает все доступное пространство */
  padding: 20px;
}

.footer {
  background-color: #333;
  color: white;
  padding: 20px;
}

/* Адаптивность для мобильных устройств */
@media (max-width: 768px) {
  .content {
    flex-direction: column; /* Меняем направление на вертикальное */
  }
  
  .sidebar {
    width: 100%; /* Сайдбар занимает всю ширину */
  }
}
```

### Выравнивание элементов внутри флекс-контейнера

Пример различных способов выравнивания элементов:

```html
<div class="container">
  <div class="item">1</div>
  <div
