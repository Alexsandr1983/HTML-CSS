# HTML справочник для начинающего программиста ## Введение HTML (HyperText Markup Language) - это стандартный язык разметки, используемый для создания веб-страниц. HTML описывает структуру веб-страницы с помощью специальных элементов, которые сообщают браузеру, как отображать содержимое. ## Основы HTML ### Структура HTML-документа Заголовок страницы

Привет, мир!

Это мой первый HTML-документ.

### Объяснение структуры: - `` - объявление типа документа, сообщает браузеру, что это HTML5 - `` - корневой элемент документа - `` - содержит метаданные/информацию о документе - `` - указывает кодировку символов - `` - определяет заголовок страницы (отображается во вкладке браузера) - `<body>` - содержит видимое содержимое страницы - `<!-- ... -->` - комментарий (не отображается на странице) ## Основные элементы HTML ### Текстовые элементы #### Заголовки HTML предлагает шесть уровней заголовков: ```html <h1>Заголовок первого уровня</h1> <h2>Заголовок второго уровня</h2> <h3>Заголовок третьего уровня</h3> <h4>Заголовок четвёртого уровня</h4> <h5>Заголовок пятого уровня</h5> <h6>Заголовок шестого уровня</h6> ``` #### Параграфы и форматирование текста ```html <p>Это параграф текста.</p> <p>Это ещё один параграф.</p> <b>Жирный текст</b> <strong>Важный текст (семантически жирный)</strong> <i>Курсивный текст</i> <em>Выделенный текст (семантически курсивный)</em> <u>Подчёркнутый текст</u> <s>Зачёркнутый текст</s> <mark>Выделенный текст</mark> <small>Мелкий текст</small> <big>Крупный текст (устаревший)</big> <sub>Подстрочный</sub> текст <sup>Надстрочный</sup> текст <pre> Предварительно отформатированный текст сохраняет пробелы и переносы строк </pre> <code>Текст кода</code> <kbd>Клавиатурный ввод</kbd> <samp>Пример вывода программы</samp> <var>Переменная</var> <blockquote> Блочная цитата - длинная цитата, оформленная как отдельный блок текста, обычно с отступом. </blockquote> <q>Строчная цитата в тексте</q> <abbr title="HyperText <ins>Вставленный текст</ins> <del>Удалённый текст</del> ``` ### Списки #### Маркированный список ```html <ul> <li>Элемент списка 1</li> <li>Элемент списка 2</li> <li>Элемент списка 3</li> </ul> ``` #### Нумерованный список ```html <ol> <li>Первый элемент</li> <li>Второй элемент</li> <li>Третий элемент</li> </ol> ``` #### Список определений ```html <dl> <dt>HTML</dt> <dd>Язык гипертекстовой <ul> <li>Яблоки</li> <li>Бананы</li> <li>Апельсины</li> </ul> </li> <li>Овощи <ul> <li>Морковь</li> <li>Капуста</li> <li>Помидоры</li> </ul> </li> </ul> ``` ### Ссылки и якоря ```html <!-- Обычная HTML ## Структурные элементы ### `<header>` **Описание:** Представляет вступительный контент или набор навигационных ссылок. **Использование:** Обычно содержит логотип, заголовок сайта, навигационное меню. **Пример:** <header> <h1>Название сайта</h1> <nav> <ul> <li><a href="/">Главная</a></li> <li><a href="/about">О нас</a></li> </ul> </nav> </header> ### `<nav>` **Описание:** Определяет раздел с навигационными ссылками. **Использование:** Для главного меню, подменю, оглавления или пагинации. **Пример:** <nav> <ul> <li><a href="#home">Главная</a></li> <li><a href="#services">Услуги</a></li> <li><a href="#contact">Контакты</a></li> </ul> </nav> ### `<main>` **Описание:** Определяет основное содержимое документа. **Использование:** Должен содержать контент, уникальный для данной страницы. **Особенности:** На странице может быть только один элемент `<main>`. **Пример:** <main> <h1>Заголовок страницы</h1> <p>Основной контент страницы...</p> </main> ### `<article>` **Описание:** Представляет самостоятельный, независимый контент. **Использование:** Для статей, постов блога, комментариев, виджетов. **Пример:** <article> <h2>Заголовок статьи</h2> <p>Текст статьи...</p> <footer>Автор: Иван Иванов</footer> </article> ### `<section>` **Описание:** Представляет тематическую группировку содержимого. **Использование:** Для разделения контента на логические части. **Пример:** <section> <h2>Наши услуги</h2> <p>Описание услуг компании...</p> </section> ### `<aside>` **Описание:** Представляет контент, косвенно связанный с основным содержимым. **Использование:** Для боковых панелей, врезок, рекламы, дополнительной информации. **Пример:** <aside> <h3>Смежные статьи</h3> <ul> <li><a href="#">Статья 1</a></li> <li><a href="#">Статья 2</a></li> </ul> </aside> ### `<footer>` **Описание:** Представляет нижнюю часть документа или раздела. **Использование:** Содержит информацию об авторских правах, ссылки на связанные документы. **Пример:** <footer> <p>© 2025 Компания. Все права защищены.</p> <address> Контакты: <a href="mailto:info@example.com">info@example.com</a> </address> </footer> ### `<div>` **Описание:** Универсальный контейнер без специфического семантического значения. **Использование:** Когда нет подходящего семантического элемента. **Пример:** ```html <div class="container"> <div class="row"> <div class="column">Содержимое</div> </div> </div> ``` ### `<hgroup>` **Описание:** Группирует заголовки разного уровня. **Использование:** Для основного заголовка с подзаголовками. **Пример:** ```html <hgroup> <h1>Основной заголовок</h1> <h2>Подзаголовок</h2> </hgroup> ``` ### `<dialog>` **Описание:** Представляет диалоговое окно или другой интерактивный компонент. **Использование:** Для модальных окон, всплывающих подсказок. **Пример:** ```html <dialog id="myDialog"> <h2>Подтверждение</h2> <p>Вы уверены, что хотите продолжить?</p> <button onclick="document.getElementById('myDialog').close()">Закрыть</button> </dialog> ``` ### `<figure>` **Описание:** Представляет самостоятельный контент, часто с подписью. **Использование:** Для иллюстраций, диаграмм, фотографий, кода. **Пример:** ```html <figure> <img src="image.jpg" alt="Описание изображения"> <figcaption>Подпись к изображению</figcaption> </figure> ``` ### `<figcaption>` **Описание:** Определяет подпись для элемента `<figure>`. **Использование:** Должен быть первым или последним дочерним элементом `<figure>`. **Пример:** См. пример для `<figure>`. ### `<details>` **Описание:** Создает виджет, который можно раскрывать/скрывать. **Использование:** Для FAQ, дополнительной информации. **Пример:** ```html <details> <summary>Подробнее о доставке</summary> <p>Доставка осуществляется в течение 2-3 рабочих дней.</p> </details> ``` ### `<summary>` **Описание:** Определяет видимый заголовок для элемента `<details>`. **Использование:** Должен быть первым дочерним элементом `<details>`. **Пример:** См. пример для `<details>`. ## Текстовые элементы ### `<h1>` - `<h6>` **Описание:** Определяют заголовки разных уровней. **Использование:** `<h1>` для основного заголовка, `<h2>` для подзаголовков и так далее. **Пример:** ```html <h1>Основной заголовок</h1> <h2>Подзаголовок</h2> <h3>Подзаголовок третьего уровня</h3> ``` ### `<p>` **Описание:** Представляет абзац текста. **Использование:** Для основного текстового содержимого. **Пример:** ```html <p>Это абзац текста. Он может содержать множество предложений.</p> ``` ### `<blockquote>` **Описание:** Представляет цитату из другого источника. **Использование:** Для выделения цитат других авторов или источников. **Пример:** ```html <blockquote cite="https://example.com/source"> <p>Это пример цитаты из другого источника.</p> </blockquote> ``` ### `<q>` **Описание:** Представляет короткую встроенную цитату. **Использование:** Для цитат внутри текста. **Пример:** ```html <p>Как сказал автор, <q cite="https://example.com/source">это короткая цитата</q>.</p> ``` ### `<cite>` **Описание:** Представляет ссылку на источник цитаты. **Использование:** Для указания авторства или источника цитаты. **Пример:** ```html <p>Согласно <cite>Википедии</cite>, HTML - это язык разметки.</p> ``` ### `<time>` **Описание:** Представляет дату или время. **Использование:** Для отображения дат публикации, событий и т.д. **Пример:** ```html <p>Статья опубликована <time datetime="2025-03-15">15 марта 2025</time>.</p> ``` ### `<address>` **Описание:** Представляет контактную информацию. **Использование:** Для контактных данных автора или организации. **Пример:** ```html <address> <a href="mailto:info@example.com">info@example.com</a><br> <a href="tel:+79001234567">+7 (900) 123-45-67</a> </address> ``` ### `<abbr>` **Описание:** Представляет аббревиатуру или акроним. **Использование:** С атрибутом `title` для объяснения аббревиатуры. **Пример:** ```html <p><abbr title="Hypertext Markup Language">HTML</abbr> - это язык разметки.</p> ``` ### `<dfn>` **Описание:** Представляет определение термина. **Использование:** При первом упоминании термина в тексте. **Пример:** ```html <p><dfn>HTML</dfn> - это язык разметки, используемый для создания веб-страниц.</p> ``` ### `<code>` **Описание:** Представляет фрагмент компьютерного кода. **Использование:** Для отображения кода программ, HTML-тегов и т.д. **Пример:** ```html <p>Тег <code><div></code> используется для группировки содержимого.</p> ``` ### `<kbd>` **Описание:** Представляет пользовательский ввод с клавиатуры. **Использование:** Для отображения клавиш или комбинаций клавиш. **Пример:** ```html <p>Нажмите <kbd>Ctrl</kbd> + <kbd>C</kbd> для копирования.</p> ``` ### `<samp>` **Описание:** Представляет вывод программы или компьютера. **Использование:** Для отображения результатов выполнения программы. **Пример:** ```html <p>Сообщение об ошибке: <samp>Файл не найден</samp>.</p> ``` ### `<var>` **Описание:** Представляет переменную или математическое выражение. **Использование:** В математических формулах или программном коде. **Пример:** ```html <p>Решение уравнения: <var>x</var> = 5.</p> ``` ### `<pre>` **Описание:** Представляет предварительно отформатированный текст. **Использование:** Для сохранения пробелов, переносов строк и т.д. **Пример:** ```html <pre> function hello() { console.log("Привет, мир!"); } </pre> ``` ### `<b>` **Описание:** Привлекает внимание к тексту без придания ему особой важности. **Использование:** Для ключевых слов, названий продуктов и т.д. **Пример:** ```html <p>Не забудьте прочитать раздел <b>Условия использования</b>.</p> ``` ### `<strong>` **Описание:** Придает тексту важность или серьезность. **Использование:** Для важных предупреждений, выводов и т.д. **Пример:** ```html <p><strong>Внимание!</strong> Эта операция необратима.</p> ``` ### `<i>` **Описание:** Выделяет текст, отличающийся от окружающего текста. **Использование:** Для технических терминов, иностранных слов и т.д. **Пример:** ```html <p>Термин <i>семантика</i> относится к значению слов.</p> ``` ### `<em>` **Описание:** Придает тексту эмоциональное ударение. **Использование:** Для выделения слов, которые меняют смысл предложения. **Пример:** ```html <p>Я <em>действительно</em> хочу, чтобы вы поняли это.</p> ``` ### `<mark>` **Описание:** Выделяет текст для справки или обозначения. **Использование:** Для выделения текста при поиске, цитировании и т.д. **Пример:** ```html <p>Это <mark>важная информация</mark>, которую стоит запомнить.</p> ``` ### `<small>` **Описание:** Представляет мелкий шрифт, дополнительные комментарии. **Использование:** Для сносок, уведомлений об авторских правах и т.д. **Пример:** ```html <p>Текст статьи. <small>© 2025 Все права защищены.</small></p> ``` ### `<s>` **Описание:** Представляет текст, который больше не является точным или актуальным. **Использование:** Для перечеркивания устаревшей информации. **Пример:** ```html <p><s>Цена: 100
