# Полный справочник по CSS Flexbox

## Введение в Flexbox

Flexbox (Flexible Box Layout) — это модуль CSS, разработанный для создания гибких и адаптивных макетов. Он предоставляет простой и мощный способ выравнивания, распределения пространства и изменения порядка элементов в контейнере, даже когда их размер неизвестен или динамически меняется.

### История и цель создания

Flexbox был введен для решения сложностей, с которыми веб-разработчики сталкивались при использовании традиционных методов верстки:
- Сложность вертикального центрирования
- Проблемы с адаптивностью макетов
- Трудности с изменением порядка элементов без изменения HTML

Модель Flexbox создана специально для одномерных макетов — в основном для организации элементов в ряды или колонки.

### Преимущества использования Flexbox

- **Гибкость**: элементы могут расти или сжиматься для заполнения доступного пространства
- **Двунаправленность**: возможность организации элементов как по горизонтали, так и по вертикали
- **Выравнивание**: простое выравнивание элементов по осям
- **Переупорядочивание**: возможность изменения визуального порядка элементов без изменения HTML
- **Адаптивность**: легкое создание адаптивных макетов без медиа-запросов

## Основные концепции

### Терминология Flexbox

Для понимания Flexbox важно познакомиться с его терминологией:

![Основная терминология Flexbox](https://developer.mozilla.org/en-US/docs/Learn/CSS/CSS_layout/Flexbox/flex_terms.png)

#### Flex-контейнер и Flex-элементы

- **Flex-контейнер (родитель)**: элемент, к которому применяется свойство `display: flex` или `display: inline-flex`
- **Flex-элементы (дети)**: прямые потомки flex-контейнера

#### Главная и поперечная оси

- **Главная ось (Main Axis)**: основная ось, вдоль которой размещаются flex-элементы
  - Направление определяется свойством `flex-direction`
  - По умолчанию идет слева направо (row)
- **Поперечная ось (Cross Axis)**: ось, перпендикулярная главной оси
  - Если главная ось горизонтальная, то поперечная — вертикальная и наоборот

#### Начало и конец осей

- **Main Start/Main End**: начало и конец главной оси
- **Cross Start/Cross End**: начало и конец поперечной оси

#### Размеры по осям

- **Main Size**: размер flex-элемента вдоль главной оси (width или height в зависимости от оси)
- **Cross Size**: размер flex-элемента вдоль поперечной оси

### Создание flex-контейнера

Чтобы начать использовать Flexbox, необходимо определить flex-контейнер:

```css
.container {
  display: flex; /* или display: inline-flex */
}
```

- `display: flex` - создает блочный flex-контейнер
- `display: inline-flex` - создает строчный flex-контейнер

## Свойства контейнера

### flex-direction

Определяет направление главной оси, по которой размещаются flex-элементы.

```css
.container {
  flex-direction: row | row-reverse | column | column-reverse;
}
```

- `row` (по умолчанию): элементы располагаются в строку слева направо
- `row-reverse`: элементы располагаются в строку справа налево
- `column`: элементы располагаются в колонку сверху вниз
- `column-reverse`: элементы располагаются в колонку снизу вверх

![flex-direction](https://css-tricks.com/wp-content/uploads/2018/10/flex-direction.svg)

### flex-wrap

Определяет, будут ли flex-элементы располагаться в одну линию или могут переноситься на новую строку.

```css
.container {
  flex-wrap: nowrap | wrap | wrap-reverse;
}
```

- `nowrap` (по умолчанию): элементы размещаются в одну линию, могут сжиматься
- `wrap`: элементы переносятся на новую строку при нехватке места
- `wrap-reverse`: элементы переносятся на новую строку в обратном порядке

![flex-wrap](https://css-tricks.com/wp-content/uploads/2018/10/flex-wrap.svg)

### flex-flow

Сокращенное свойство для `flex-direction` и `flex-wrap`.

```css
.container {
  flex-flow: <flex-direction> <flex-wrap>;
}
```

Например:
```css
.container {
  flex-flow: row wrap;
}
```

### justify-content

Определяет выравнивание элементов вдоль главной оси.

```css
.container {
  justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;
}
```

- `flex-start` (по умолчанию): элементы прижимаются к началу главной оси
- `flex-end`: элементы прижимаются к концу главной оси
- `center`: элементы центрируются вдоль главной оси
- `space-between`: первый элемент в начале, последний в конце, остальные равномерно распределены
- `space-around`: равномерное распределение с одинаковым пространством вокруг элементов
- `space-evenly`: равномерное распределение с одинаковым пространством между элементами и краями

![justify-content](https://css-tricks.com/wp-content/uploads/2018/10/justify-content.svg)

### align-items

Определяет выравнивание элементов вдоль поперечной оси.

```css
.container {
  align-items: stretch | flex-start | flex-end | center | baseline;
}
```

- `stretch` (по умолчанию): элементы растягиваются по высоте контейнера
- `flex-start`: элементы выравниваются по началу поперечной оси
- `flex-end`: элементы выравниваются по концу поперечной оси
- `center`: элементы центрируются по поперечной оси
- `baseline`: элементы выравниваются по базовой линии текста

![align-items](https://css-tricks.com/wp-content/uploads/2018/10/align-items.svg)

### align-content

Определяет выравнивание строк flex-элементов внутри контейнера, когда есть дополнительное пространство по поперечной оси. Работает только при `flex-wrap: wrap` или `flex-wrap: wrap-reverse` и при наличии нескольких строк элементов.

```css
.container {
  align-content: flex-start | flex-end | center | space-between | space-around | space-evenly | stretch;
}
```

- `stretch` (по умолчанию): строки растягиваются, заполняя контейнер
- `flex-start`: строки группируются в начале контейнера
- `flex-end`: строки группируются в конце контейнера
- `center`: строки группируются по центру контейнера
- `space-between`: первая строка вверху, последняя внизу, остальные равномерно распределены
- `space-around`: строки равномерно распределены с пространством вокруг каждой
- `space-evenly`: строки равномерно распределены с одинаковым пространством между ними

![align-content](https://css-tricks.com/wp-content/uploads/2018/10/align-content.svg)

### gap, row-gap, column-gap

Определяет расстояние между flex-элементами.

```css
.container {
  gap: <row-gap> <column-gap>;
  row-gap: <значение>;
  column-gap: <значение>;
}
```

- `gap`: сокращенное свойство для установки обоих промежутков
- `row-gap`: промежуток между строками
- `column-gap`: промежуток между столбцами

![gap](https://css-tricks.com/wp-content/uploads/2021/09/gap-1.svg)

## Свойства элементов

### order

Определяет порядок отображения flex-элемента. Элементы располагаются в порядке возрастания значения свойства `order`.

```css
.item {
  order: <целое_число>; /* по умолчанию 0 */
}
```

![order](https://css-tricks.com/wp-content/uploads/2018/10/order.svg)

### flex-grow

Определяет способность flex-элемента растягиваться (занимать доступное пространство). Принимает безразмерное значение, которое служит пропорцией.

```css
.item {
  flex-grow: <число>; /* по умолчанию 0 */
}
```

Если всем элементам установить `flex-grow: 1`, они займут равное пространство. Если одному элементу установить `flex-grow: 2`, а остальным `flex-grow: 1`, то первый будет занимать в два раза больше пространства.

![flex-grow](https://css-tricks.com/wp-content/uploads/2018/10/flex-grow.svg)

### flex-shrink

Определяет способность flex-элемента сжиматься при нехватке места.

```css
.item {
  flex-shrink: <число>; /* по умолчанию 1 */
}
```

Чем больше значение, тем больше элемент будет сжиматься по сравнению с другими. Значение 0 означает, что элемент не будет сжиматься.

### flex-basis

Определяет базовый размер элемента вдоль главной оси перед распределением дополнительного пространства.

```css
.item {
  flex-basis: <длина> | auto; /* по умолчанию auto */
}
```

- `auto`: смотрит на свойства width/height
- `<длина>`: конкретный размер (px, em, %) или content

### flex

Сокращенное свойство для `flex-grow`, `flex-shrink` и `flex-basis`.

```css
.item {
  flex: <flex-grow> <flex-shrink> <flex-basis>;
}
```

Рекомендуемые комбинации:
- `flex: 1 1 auto` или `flex: auto` - элемент занимает все доступное пространство и может сжиматься
- `flex: 0 1 auto` или `flex: initial` - элемент принимает размер содержимого и может только сжиматься
- `flex: 0 0 auto` или `flex: none` - элемент неэластичный (размер фиксирован)
- `flex: 1` или `flex: 1 1 0%` - элемент занимает все доступное пространство

### align-self

Переопределяет значение `align-items` для конкретного flex-элемента.

```css
.item {
  align-self: auto | flex-start | flex-end | center | baseline | stretch;
}
```

![align-self](https://css-tricks.com/wp-content/uploads/2018/10/align-self.svg)

## Практические примеры

### Центрирование элемента

Одна из самых популярных задач — центрирование элемента как по горизонтали, так и по вертикали:

```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh; /* для вертикального центрирования на всю высоту экрана */
}
```

### Навигационное меню

Создание гибкого навигационного меню:

```css
.nav {
  display: flex;
  justify-content: space-between; /* или space-around */
  list-style: none;
  padding: 0;
}

.nav-item {
  /* Стили для элементов меню */
}

/* Для равных размеров элементов */
.nav-item {
  flex: 1;
  text-align: center;
}
```

### Карточки одинаковой высоты

Создание сетки с карточками одинаковой высоты:

```css
.card-container {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card {
  flex: 1 0 300px; /* Основа 300px, возможность растягиваться, но не сжиматься */
}
```

### Макет "Святой Грааль"

Классический макет с шапкой, подвалом, контентом и двумя боковыми колонками:

```css
.holy-grail {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}

.header, .footer {
  flex: 0 0 auto;
}

.main-content {
  display: flex;
  flex: 1 0 auto;
}

.content {
  flex: 1 0 auto;
}

.left-sidebar, .right-sidebar {
  flex: 0 0 200px; /* Фиксированная ширина боковых панелей */
}
