Пример 2: Карточки с равной высотой

.cards-container {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card {
  flex: 1 0 250px;
}

Карточка 1

Содержимое карточки. Flexbox автоматически делает все карточки одинаковой высоты.

Карточка 2

Карточка с большим содержимым. Обратите внимание, что все карточки растягиваются до высоты самой высокой карточки.

Дополнительный текст для увеличения высоты.

Пример 5: Адаптивная сетка

.grid {
  display: flex;
  flex-wrap: wrap;
  gap: 15px;
}

.grid-item {
  flex: 1 0 calc(25% - 15px);
}

@media (max-width: 768px) {
  .grid-item {
    flex: 1 0 calc(50% - 15px);
  }
}
